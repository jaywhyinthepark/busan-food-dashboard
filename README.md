# 부산 음식업 상권 대시보드

2026년 9월 부산의 법정구역별 음식업 점포를 비교하고, 소상공인 상담에서 확인할 질문을 준비하는 개인 프로젝트다.

- **지표별 상위 5곳**에서 음식 점포 수, 주민 1천 명당 음식 점포 수, 음식업 특화도를 각각 비교한다.
- **법정구역별 점포 분포**에서 구·군과 지역을 선택해 점포 수, 주민등록인구, 음식업 구성비와 지도를 확인한다. 지도는 음식업 세부 업종으로 필터링할 수 있다.
- **상담 질문**은 고객 구성, 매출 정산과 비용 지급 시점, 상환 재원을 확인하는 데 쓴다.

## 로컬 실행

Python 3.11 환경에서 아래 명령을 실행한다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

대시보드용 CSV를 포함했으므로 실행에 원본 엑셀이나 별도 API 키가 필요하지 않다. 지도 배경을 표시할 때는 인터넷 연결이 필요하다.

## GitHub에 올리기

새 저장소를 만든 뒤 이 폴더 안의 파일을 저장소 최상위에 올린다. `app.py`, `requirements.txt`, `data/`를 같은 수준에 둔다. `.streamlit/config.toml`을 함께 올리면 앱의 색상 설정이 적용된다. GitHub는 코드 저장에 쓰고, 웹에서 실행하려면 [Streamlit Community Cloud](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy)를 통해 저장소를 연결하고 실행 파일을 `app.py`로 지정한다.

## 자료와 계산 기준

- 점포 수와 업종 및 좌표는 [소상공인시장진흥공단 상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do) 부산 자료를 사용했다. 상권업종대분류 코드 `I2`를 음식업으로 집계했다.
- 인구는 [행정안전부 법정동별 주민등록 인구통계](https://jumin.mois.go.kr/)의 2026년 9월 총인구를 사용했다. 상가 자료와 10자리 법정동코드로 연결했다.
- `data/areas.csv`에는 상가 자료에 등장하는 법정구역의 인구와 점포 수가 있다. 특화도는 지역 음식업 구성비를 부산 전체 음식업 구성비로 나눈 값이다. 인구가 0명인 지역은 주민 1천 명당 점포 수를 계산하지 않는다.
- `data/food_map.csv`에는 음식업 점포를 법정구역·세부 업종·반올림한 좌표(소수 셋째 자리)별로 묶은 건수가 있다. 지도 원은 집계 위치를 나타낸다. 점포명, 개별 주소, 상가업소번호는 CSV에 들어 있지 않다.
- 주민등록인구 대비 점포 수는 유동인구, 매출, 대출 수요 또는 상환능력의 측정값이 아니다.

## 데이터 다시 만들기

같은 구조의 작업용 엑셀을 저장한 뒤 아래 명령으로 CSV를 다시 만들 수 있다. 파일에는 계산 결과가 저장된 `집계표_값`과 상가 원본 시트가 필요하다. 스크립트는 두 시트의 법정구역별 전체·음식 점포 수가 일치하는지 확인한다. 기준월이 바뀌면 `app.py`의 화면 설명과 이 문서의 기준월도 갱신한다.

```bash
python prepare_data.py "상가_소상공인시장진흥공단_상가(상권)정보_부산.xlsx"
```
